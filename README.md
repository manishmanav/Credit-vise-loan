# Loan Approval Prediction

## Project Description
This project uses Machine Learning to predict whether a loan application will be approved based on applicant details. It includes data preprocessing, exploratory data analysis (EDA), model training, and performance evaluation using Python.

## Dataset
**Dataset:** Credit vise loan

**Dataset Link:**  
https://github.com/manishmanav/Credit-vise-loan/blob/main/creditvise_loan_data.csv

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## How to Run
1. Clone this repository.
2. Install the required libraries.
3. Open `Manish_code.ipynb` in Jupyter Notebook.
4. Run all cells.
